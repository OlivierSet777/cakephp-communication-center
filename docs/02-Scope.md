# Scope

## Version 0.1 scope

Version 0.1 focuses on the smallest useful product:

- campaigns;
- campaign recipients;
- message templates;
- recipient provider contract;
- WhatsApp deep-link channel;
- mobile recipient selection;
- per-recipient progress tracking;
- basic history.

## Explicitly excluded from version 0.1

- automatic WhatsApp sending;
- reading WhatsApp replies;
- attachments;
- scheduled campaigns;
- SMS billing integration;
- email queue;
- analytics beyond basic counts;
- webhooks;
- external API.

These features remain candidates for later versions.

## Definition of done for the host application pilot

The pilot is complete when an administrator can perform a monthly contribution reminder without manually searching contacts in WhatsApp.
